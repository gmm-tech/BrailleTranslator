# BrailleTranslator ⠃⠗⠁⠊⠇⠇⠑

A simple and clean braille translator.

Text in. Braille out. No unnecessary distractions.

Built with **Python**.

### Features

* [X] Translate a text string directly in the terminal
* [ ] Translate a text file (`.txt`) and print the braille in the terminal
* [ ] Recreate a `.txt` file in braille as a new file
* [ ] Rule system to create translation rules for languages beyond English
* [ ] Turn the project into a reusable Python library installable via pip


### Built with

`Python`
